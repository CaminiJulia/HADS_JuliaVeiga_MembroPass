# Banco de Dados

Scripts SQL exigidos pela disciplina (item 2.1 do Plano de Ensino):

- `01_criacao.sql`: criação das tabelas
- `02_dados_teste.sql`: dados para testes
- `03_regras_negocio.sql`: triggers e procedures

As tabelas da API são gerenciadas pelas migrations do Prisma (`api/prisma/`). Estes scripts são a
versão SQL equivalente, entregue junto com o projeto.
